# Застосунок обліку транзакцій

## Опис
Додаток призначений для обліку витрат з можливістю додавання транзакцій (сума, категорія, дата), відображенням загальної суми та списку транзакцій, згрупованих по датах.

### Основні файли
```
expense-track/
├── app/
│   ├── _layout.tsx          # Макет додатку
│   └── index.tsx            # Головний екран
│
├── components/
│   ├── TransactionForm.tsx  # Модальне вікно форми
│   ├── TransactionList.tsx  # Список транзакцій
│   ├── TransactionGroup.tsx # Групування за датою
│   └── TransactionItem.tsx  # Окремий елемент транзакції
│
├── types/
│   └── Transaction.ts       # TypeScript типи даних
│
├── package.json             # Залежності проєкту
├── tsconfig.json            # Конфігурація TypeScript
```

### Використані бібліотеки 
| Бібліотека | Версія | Призначення |
|------------|--------|-------------|
| expo | ~54.0.34 | Фреймворк для React Native |
| react-native | 0.81.5 | Основна бібліотека для мобільної розробки |
| expo-router | ~6.0.23 | Навігація та маршрутизація |
| @react-native-community/datetimepicker | 9.1.0 | Вибір дати |
| react | 19.1.0 | JavaScript бібліотека для UI |


## Встановлення

1. Встановлення залежностей

   ```bash
   npm install
   ```

2. Запуск застосунку

   ```bash
   npx expo start
   ```
